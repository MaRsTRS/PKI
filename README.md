# Развёртывание удостоверяющего центра (PKI)


## Установка
Критически важный компонент - необходимо установить зависимость easy-rsa

1. Клонирование репозитория 

```git clone https://github.com/MaRsTRS/PKI.git```

2. Установка deb пакета pki_1.0.0-1_all.deb

```sudo apt install ./pki_1.0.0-1_all.deb```

3. Настройка безопасности для сервера. Отключаем вход по паролю для протакола ssh

```sudo sed -i "s/PasswordAthentication yes/PasswordAuthentication no/ /etc/ssh/sshd_config```

```sudo systemctl restart ssh.service```

4. Настройка файрвола iptables. Разрешаем входящий траффик по протоколу ssh.

```sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT```

```sudo iptables -A INPUT -p tcp --dport 80 -j DROP```

```sudo iptables -A INPUT -p tcp --dport 443 -j DROP```

5. Установка зависимостей
   
  ```sudo apt install easy-rsa```	

6. Запуск скрипта CA-CERT

  ```cd /opt/easy-rsa/CA-CERT```
  
  ```./CA-CERT```

7. Установка ключа сертифицированного центра 

```cd ~/easy-rsa/```

```./easyrsa init-pki```

```cp /opt/easy-rsa/vars ~/easy-rsa```

```./easyrsa build-ca```



## 1. Краткое описание проекта

Проект разворачивает удостоверяющий центр (Certificate Authority) на базе Easy-RSA. CA предназначен для выпуска и подписи сертификатов, которые в
дальнейшем используются компонентами инфраструктуры: OpenVPN-сервером, мониторингом
и другими сервисами.

Ключевые принципы реализации:
- идемпотентность — повторный запуск скрипта не пересоздаёт ключи и не ломает систему;
- безопасность — приватные ключи имеют права 0400, вход по паролю на сервер отключён;
- воспроизводимость — все параметры CA заданы в конфигурационном файле, ручной ввод исключён.

## 2. Требования к инфраструктуре

- Облако: Виртуальная машина (каталог, платёжный аккаунт).
- Роли IAM: compute.admin, vpc.admin.
- Виртуальная машина pki-server:
  - ОС: Ubuntu 22.04 LTS;
  - ресурсы: 2 vCPU / 4 GB RAM;
  - диск: 50 GB;
  - IP: статический публичный.
  - Сеть:
  - VPC, подсеть по умолчанию;
  - группа безопасности: разрешён только 22/TCP (SSH) с ограничением по IP-адресам;
  - все остальные порты закрыты.
  - Доступ: SSH-ключ, добавленный в метаданные ВМ; вход по паролю отключён.

## 3. Предварительно установленные инструменты

На локальной машине:
- SSH-клиент (OpenSSH);
- Git (для клонирования репозитория).

На сервере pki-server (устанавливаются скриптом автоматически, но приведены для справки):
- easy-rsa — генерация и подпись сертификатов;
- openssl — проверка сертификатов (входит в базовый набор Ubuntu).

## 4. Как развернуть и пользоваться проектом

Ручные шаги:
1. Создать ВМ pki-server (Ubuntu 22.04, 2 vCPU / 4 GB RAM, 50 GB).
2. Выделить статический публичный IP и привязать его к ВМ.
3. Настроить группу безопасности: входящий 22/TCP только с вашего IP.
4. Подключиться по SSH и отключить парольный вход:
   в /etc/ssh/sshd_config установить PasswordAuthentication no,
   затем: sudo systemctl restart ssh.service.

Автоматические шаги:
1. Склонировать репозиторий: git clone https://github.com/MaRsTRS/PKI.git 
2. Перейти в каталог проекта: cd ~/PKI
3. Запустить пакет (установка) sudo apt install ./pki_1.0.0-1_all.deb
4. После установки зайти /opt/easy-rsa/CA-CERT
5. Запустить скрипт CA-CERT

При первом запуске скрипт устанавливает easy-rsa, инициализирует PKI и создает
корневой сертификат CA. При повторном запуске скрипт обнаруживает существующий файл
ca.crt и завершается без изменений.

Проверка результата:
- наличие сертификата: ls ~/easy-rsa/pki/ca.crt
- проверка содержимого: openssl x509 -in ~/easy-rsa/pki/ca.crt -noout -text

## 6. Схема взаимодействия компонентов

 											Интернет
                                               |
                                        [Администратор]
                                               |
                                               | SSH (22/TCP)
                             _____________________________________                |
                            |									  |
                            │  Virtual Machine (VPC)              │
                            │                                     │
                            │   ___________________________ 	  |
                            │  │ pki-server                │      │
                            │  │ - Easy-RSA (CA)           │      │
                            │  │ - хранение ключей CA      │      │
                            │  |						   |	  |	
                            │  |___________________________|      |
                            │                                     │
                            |_____________________________________|
                                               
                                               |  
                                               | 
                                               | scp копирование сертификата
                                               | 
                                               |
                                          [OpenVPN-server]
 

Администратор подключается к pki-server по SSH и запускает скрипт развёртывания.
Скрипт генерирует ключ и корневой сертификат CA. В дальнейшем полученные
сертификаты передаются целевым сервисам (например, OpenVPN-серверу) по SSH/scp.
